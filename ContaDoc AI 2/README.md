# ContaDoc AI Enterprise - Intelligent Accounting Notebook

## Project Overview
A high-end AI-powered research and learning assistant specifically designed for accounting firms. It uses a RAG (Retrieval-Augmented Generation) architecture to allow accountants to interact with their own client data.

## Tech Stack
- **Backend:** FastAPI (Python)
- **AI Orchestration:** LangChain / LlamaIndex
- **LLM:** Claude 3.5 Sonnet (via API)
- **Vector DB:** ChromaDB
- **Frontend:** Next.js 14, Tailwind CSS, Shadcn/UI
- **Document Processing:** Unstructured.io / PyPDF2 / Pandas

## Core Features
- Client-specific workspaces (isolated data indices)
- Multi-modal document ingestion (PDF, XLSX, Images)
- Source-grounded answers (direct citations from docs)
- Accounting-specialized prompt engineering
- Automated data extraction to structured formats
